已修正
1. 顶部 X 替换为右上角齿轮；悬浮球设置独立弹窗包含 50–150% 大小、预览、潜航开关与 0.9 秒手势说明。设置底部返回大厅，主窗口底部长条返回收起窗口，关闭不退出联机。
2. 设置 DOM 独立于房间快照渲染。背景 inert、Tab 焦点循环、返回恢复焦点；Escape 只在本窗口拥有焦点时处理，一次返回一层，长按不连退。保留草稿、滚动和展开状态。
3. 大厅 CSS 限定到自身根节点，避免 mm-message 等通用类污染其他工具。
4. 房主创建/恢复捕获本次生命周期，异步身份生成、密码派生、信令分配和错误回调检查有效性；关闭后迟到连接销毁，旧失败不能终止新房间。断线重试计时器纳入清理。
5. PeerJS 连接成功移除启动阶段 open/error 处理器，后续错误交由当前连接处理，不误销毁整个活动 Peer。
6. UI dispose 幂等且移除自身键盘/pagehide 监听，旧实例不能删除新的全局实例标记。
